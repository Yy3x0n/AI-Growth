# 指标字典（Metric Dictionary）

> 版本：v1.0　｜　对应阶段：2　｜　口径实现：`sql/02_kpi_analysis.sql`（基准）
> 第二实现：`src/metrics.py`　｜　对账结果：`outputs/tables/kpi_sql_vs_pandas.csv`（17 项全一致）
>
> **口径类型说明**（本字典的核心字段）：
> - `真实`：数据中存在可直接计算的字段，无代理
> - `代理`：字段缺失，用可得信号近似，必须在使用处标注
> - `模拟`：真实数据无法支撑，只能用模拟数据计算
> - `不可计算`：数据中不存在必要条件，**不允许用近似值填充**

---

## 0. 全局口径约束

| 项 | 规定 | 原因 |
|---|---|---|
| 统计主体 | **account**（企业账户） | 数据无 user / session 粒度，DAU 类指标不可计算 |
| 时间基准 | **自然月**（2023-01 ~ 2024-12，共 24 个月） | 日级数据过于稀疏（每账户约 50 条摊到 730 天） |
| 时间锚点 | **不使用 `signup_date`** | 490/500 账户首次使用早于注册日，锚点失效（Q-23） |
| 收入口径 | 账户-月快照 + 胜出订阅 | 89.3% 的账户-月有多条重叠订阅 |
| 流失口径 | `churn_events` 去重账户（排除复活） | 三套口径差异已在 Q-17 披露 |
| 数值校验 | SQL 与 Pandas 全量逐格比对，容差 1e-6 | 抽样核对不足以发现 join 错误 |

## 1. 规模类指标

| 指标 | 定义 | 口径类型 | 来源 | 限制 |
|---|---|---|---|---|
| 账户总数 | `COUNT(DISTINCT account_id)` | 真实 | `raw_accounts` | 500，为数据全集，不随时间增长 |
| 新增账户数 | 当期首次出现使用记录的账户数 | **代理** | `v_account_feature_span` | **不是注册数**。注册口径不可用，见 Q-23 |
| 活跃账户数 | 当期有 ≥1 条使用记录的账户数 | 真实 | `v_usage_account` | 不含 `usage_count=0` 的特殊口径未单列 |
| 付费账户数 | 当期有有效订阅的账户数 | 真实 | `v_account_month` | 以月末快照判定，非"当月有收入" |
| 停止付费账户数 | 末月 `mrr=0` 的账户数 | 真实 | `v_account_profile` | 69 个；比 `churn_flag` 更接近实际停付 |

## 2. 收入类指标

| 指标 | 定义 | 口径类型 | 来源 | 限制 |
|---|---|---|---|---|
| MRR | 账户-月快照中胜出订阅的 `mrr_amount` 合计 | 真实 | `v_account_month` | 未经汇率换算，全部为美元 |
| ARPA | `MRR / 付费账户数` | 真实 | `v_kpi_monthly` | 分母为 0 时返回 NULL，不返回 inf |
| 峰值 MRR | 账户全期 `mrr_amount` 最大值 | 真实 | `v_account_profile` | 用于识别"曾经的大客户" |
| 升级 / 降级账户数 | 当月 `upgrade_flag` / `downgrade_flag = 1` 的账户数 | 真实 | `v_account_month` | 标志位取自订阅记录，非事件流 |
| 套餐结构 | 按 `plan_tier` 的账户数与 MRR | 真实 | `v_kpi_plan_mix` | 账户的 `plan_tier` 与订阅的可能不一致，此处用订阅侧 |
| 净收入留存 NRR | — | **不可计算** | — | 缺少期初/期末同群订阅的完整序列，重叠订阅无法可靠归因 |
| 退款金额 | `refund_amount_usd` 合计 | 真实 | `raw_churn_events` | 600 条中仅 142 条非零 |

## 3. 使用与功能类指标

| 指标 | 定义 | 口径类型 | 来源 | 限制 |
|---|---|---|---|---|
| 功能渗透率 | 当月使用该功能的账户数 / 当月活跃账户数 | 真实 | `v_kpi_feature_month` | 40 个功能取值为 `feature_1..40`，**无业务语义** |
| 户均使用功能数 | 账户去重功能数均值 | 真实 | `v_account_feature_span` | 称"户均"不称"人均"；实测 27.6（范围 9~40） |
| 使用记录数 | 账户的使用事件条数 | 真实 | 同上 | `usage_id` 有 21 行重复，按行计数不去重 |
| 任务成功率 | — | **代理** | — | 无 `task_success` 字段，用 `error_count = 0` 的记录占比近似 |
| 错误率 | `error_count > 0` 的记录数 / 总记录数 | **真实（代理口径）** | `v_account_feature_span` | 全量 30.92%；账户级 P90 = 0.394 |
| 平均使用时长 | `usage_duration_secs` 均值 | 真实 | 同上 | 单位秒，无业务上限校验 |
| Beta 功能使用 | `is_beta_feature = 1` 的记录数 | 真实 | `v_kpi_feature_summary` | 可作为"尝鲜型客户"信号 |

## 4. 服务类指标

| 指标 | 定义 | 口径类型 | 来源 | 限制 |
|---|---|---|---|---|
| 工单量 | 当月经 `submitted_at` 归月的工单数 | 真实 | `v_kpi_support` | 一账户可多工单 |
| 首次响应时长 | `first_response_time_minutes` 均值 | 真实 | 同上 | 无 SLA 基准可比，只能横向比较 |
| 解决时长 | `resolution_time_hours` 均值 | 真实 | 同上 | 未关闭工单按原值参与均值，未单独剔除 |

| CSAT | `satisfaction_score` 均值 | 真实（**分母受限**） | 同上 | 空值 825/2,000（41.25%），分母只能用 1,175 条非空 |

## 5. 流失类指标

| 指标 | 定义 | 口径类型 | 来源 | 限制 |
|---|---|---|---|---|
| 流失账户数（主口径） | `churn_events` 中去重、且排除复活事件的账户数 | 真实 | `v_kpi_churn` | **339** |
| 流失账户数（事件口径） | `churn_events` 去重账户数 | 真实 | 同上 | 352（含仅有复活事件的账户） |
| 流失账户数（标签口径） | `accounts.churn_flag = 1` | 真实 | 同上 | 110，与前两者差异已在 Q-17 披露 |
| 流失率 | 流失账户数 / 账户总数 | 真实 | 同上 | 主口径 67.8%；标签口径 22.0%——**引用时必须带口径名** |
| 复活事件数 | `is_reactivation = 1` 的事件数 | 真实 | 同上 | 61 条 |
| 流失前兆信号 | 流失前是否降级/升级 | 真实 | `v_churn_leading_signals` | 存在"先升级后流失"的反直觉样本 |
| 流失原因分布 | 按 `reason_code` 分组 | 真实 | `v_kpi_churn_reason` | 6 类，`unknown` 占 86 事件 |

## 6. 生命周期类指标（**真实数据不可计算**）

| 指标 | 定义 | 口径类型 | 说明 |
|---|---|---|---|
| 激活率（注册后 7 日） | 注册后 7 日内完成首次有效使用的账户占比 | **模拟** | 实测仅 7/500 账户满足，且时间轴不连贯（Q-23） |
| 首次有效任务完成率 | 首次使用中 `task_success` 的比例 | **不可计算** | 无 `task_success` 字段；只能给 `error_count=0` 的代理值且须标注 |
| 7 日 / 30 日留存 | 首次使用后 7/30 日仍有使用的账户占比 | **模拟** | 真实数据的"首次使用"88% 集中在数据起始月，队列退化 |
| 同期群留存（M+1…） | 按首次使用月分组的次月留存 | **模拟** | 同上；真实数据算出的 M+1≈83% 只是"每月都活跃"的稳态，不是留存 |
| 功能采用演化 | 账户从"用 1 个功能"到"用多 个功能"的路径 | **不可计算** | 每账户起点已用 9 个功能，无演化过程 |
| A/B 实验结论 | 新手引导对激活的影响 | **模拟** | 见阶段 3 |

> 这一节是本项目最重要的诚实性声明：**上表六项指标一个都没有用真实数据硬算**。
> 详见 [`data_capability_assessment.md`](data_capability_assessment.md)。

## 8. 复算命令

```bash
source .venv/bin/activate
python scripts/load_to_mysql.py                      # 装载
python scripts/run_sql.py sql/02_kpi_analysis.sql    # 建视图
python scripts/run_analysis.py                       # 指标 + 对账
python scripts/run_sql.py sql/03_customer_segments.sql
python scripts/segment_accounts.py                   # 分层 + 对账
pytest -q                                            # 16 个单测
```

任一步骤的退出码非 0 即表示口径不一致，不允许继续往下做。
